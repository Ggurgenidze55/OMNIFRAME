## 📏 **Image Requirements:**

- **Format:** JPG or PNG (JPG preferred for photos)
- **Dimensions:** 800x450px (16:9 aspect ratio)
- **Alternative:** 600x400px (3:2 aspect ratio)
- **Quality:** High quality, optimized for web
- **File size:** Under 300KB each (optimized)

## 🎯 **SEO Benefits:**

- **Descriptive filenames** improve search indexing
- **Keywords in URLs** boost content relevance
- **Topic-specific naming** helps with image search
- **Alt text friendly** names for accessibility

## 🔗 **Usage Pattern:**

```jsx
// In blog content sections:
<img 
  src="/assets/img/blog/content/javascript-frameworks-comparison-chart.jpg" 
  alt="JavaScript Frameworks 2024 Comparison Chart"
  className="w-100"
/>
```

## 📂 **File Organization:**

- Use hyphens (-) not underscores (_) in filenames
- Include main topic keyword first
- Add descriptive detail second
- Keep filenames under 50 characters
- Use consistent naming pattern

## ⚡ **Performance Tips:**

- Optimize images before uploading
- Use WebP format when possible
- Implement responsive images
- Add proper alt text for accessibility
