# Blog Featured Images

This folder contains the main featured images for blog articles. These images are displayed prominently in blog listings and individual blog posts.

## 📏 **Image Requirements:**

- **Format:** JPG or PNG (JPG preferred for photos)
- **Dimensions:** 1200x630px (recommended for social sharing)
- **Alternative:** 1920x1080px for large displays
- **Quality:** High quality, optimized for web
- **File size:** Under 500KB (optimized)

## 🎯 **SEO Benefits:**

- **Descriptive filenames** improve search engine indexing
- **Keywords in URLs** boost content relevance
- **Consistent naming** helps with site organization
- **Alt text friendly** names for accessibility

## 🔗 **Usage in Code:**

```jsx
// Example usage in blog components:
<img 
  src="/assets/img/blog/featured/javascript-frameworks-2024-guide.jpg" 
  alt="JavaScript Frameworks 2024 Complete Guide - React, Vue, Angular Comparison"

```

## 📂 **File Organization:**

- Main featured images go directly in this folder
- Use hyphens (-) not underscores (_) in filenames
- Include relevant keywords and year when applicable
- Keep filenames under 60 characters

## ⚡ **Performance Tips:**

- Optimize images before uploading (use tools like TinyPNG)
- Consider WebP format for better compression
- Implement responsive images for different screen sizes
- Use lazy loading for better page performance
